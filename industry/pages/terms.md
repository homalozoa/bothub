> 机器人热点聚合公开来源，使用模型自动筛选并生成中文摘要。公开网站、RSS、API 与 MCP 无需注册。摘要是阅读索引，重要判断请查看原文及其条件。

## 1. 内容与证据

标题、摘要、推荐理由与简报可能由模型生成，可能出现遗漏或错误；自动筛选不等于人工审核、独立事实验证或新闻真实性概率。两次模型评分用于编辑筛选，并不代表两个独立信源。厂商陈述、仿真、真机、演示与独立复现需按材料分别理解。产品性能、采购与商业判断应核对原始材料。

## 2. 版权与来源

原文和第三方素材版权归对应权利人。当前信源默认只公开摘要和原文链接，全文展示默认关闭；只有明确获得允许后才可按对应来源权限开放。本站不授予原文、图片、数据集、模型权重或代码的再使用权，具体许可应到来源查看。框架开源许可不等于聚合内容的许可。

## 3. 更正、撤回与反馈

读者和来源方可通过[反馈页](/feedback)指出错误、权利问题或撤回需求，请附站内条目与原文地址，并说明需要处理的事实。运营者可通过后台更正或撤回；公开网页、RSS、API 和 MCP 统一遵循发布状态。正式联系地址与处理时限由运营者在上线前补充，不在本草稿中承诺固定时限。

## 4. 公开接口与数据使用

RSS、公开 API 和 MCP 提供匿名只读访问。请遵守响应中的缓存、限流和 Retry-After，不绕过权限、访问控制或撤回状态，不并发反复重试。个人阅读和内部研究也需遵守来源自身的许可；批量再分发、公开转载与商业再使用范围，须由运营者正式确认，不能由本草稿推定授权。

## 5. 服务范围

本站目前为开发版本，不保证覆盖完整、内容准确或持续可用。日报按配置刊期生成，信息不足时允许少量或空刊，不承诺每天固定条数。本草稿不替代正式运营条款。
