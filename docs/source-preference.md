# 来源语言偏好

2026-10-03（Asia/Singapore），运营者要求信息源默认尽量使用非简体中文材料。

## 默认选择

- 优先英语、日语及可验证的繁体中文原始材料，尤其是项目官网、官方发布、原论文、官方代码仓库和有原文链路的专业报道。
- 来源语言以实际发布材料为准，不根据作者国籍、机构所在地区或网站域名推断。中国团队的英文论文、代码与官方英文公告可正常收录。
- 来源验证仍检查原文URL、日期、正文和机器人关联；官方宣布、厂商自报、仿真、真机及独立复现继续分别表达，不因语言而自动提高分数。
- 站内界面、标题、摘要和译文继续使用中文。原文链接和原始日期保留。
- 新增来源先检查实际语言与出处。简体中文源不进入默认启用列表；如确有特殊一手材料需要例外，单独明确记录理由并由运营者决定。

## 已执行

量子位 `rss-qbitai` 已通过现有 `updateSource` 管理流程将 `enabled` 改为false，记录审计理由，保留来源配置、历史材料和已发布内容。此次是来源语言取舍，不是对每篇旧报道作失实结论，也没有批量撤回或删库。

它从 `industry/sources.json` 的默认启用列表移入 `industry/source-candidates.json`，保持禁用，防止新部署默认重建这个源。当前启用配置为19个来源（18个英文、1个日文）；另外有9个尚未接入候选及1个按此偏好停用的来源。原20源技术验证报告保留原检查时间，不改写历史结果。

采集器仍支持中文，未来明确批准的例外可以由管理员设置。此次没有新增自动简繁识别模型、提高评分门槛、修改中文摘要输出或重跑旧文章分析。
