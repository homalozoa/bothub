# 综合精选跨领域展示修正

2026-10-03，针对“精选只看到旧机器人方向，没有新增领域内容”的反馈，发布应用版本 `d2803dd`。

核对发现两个原因：精选/完整动态仍用硬件与系统、研究与开源、产品与商业化作为主要筛选，容易被理解成领域导航；综合精选按时间分页，机器人新稿多，生物学两条原始日期较早的精选不在首屏。此外首页忽略domain查询参数，用户直接用/?domain=biology仍读取综合流。

## 修复

- 首页直接呈现四领域的真实精选概览，沿用publication选中集，不新增评分或模型调用。生物学现有入选文章可在综合首屏看到。
- 同一事件在概览只展示一次；其他领域共享该精选时注明已在其他领域展示。真正没有精选时显示公开已收录数量，并提供查看最新的链接，避免把暂无精选当成未采集。
- 旧方向按钮替换为跨领域内容形态与一手来源筛选。既有category URL、API与订阅key继续解析，使用旧方向链接时显示“原方向”提示，可通过全部形态清除。
- 首页domain被正确传入读取层，域筛选作用于分页、返回缓存、内容形态和搜索；选择单一领域后直接显示该领域精选，不再保留整块综合宣传与其他领域预览。
- /all的领域切换继续停留在最新/搜索视图，并保留关键词和内容形态；不会切到默认精选页面。

没有降低门槛，没有把未入选资料伪装为精选。AI与Agent已收录8条、社会学10条但暂无当前精选，是上线检查时的真实状态；数量随采集更新。来源、模型配置、预算、原始日期及旧机器人订阅未改。

## 验证与发布

类型检查、Web构建、604项完整后端测试、42项前端测试通过；新增SSR回归覆盖真实生物学预览、诚实空状态、domain向上游传递、搜索范围与最新视图保持。35项针对发布、频道与主题时刻的回归也通过。网页读取仅增加受public scope约束的四项计数，没有付费调用。

本机smoke和公网43项smoke通过。线上检查确认release=d2803dd、首页包含生物学实际入选文章的规范链接、旧机器人方向按钮消失、/?domain=biology正确显示生物学精选。手机生物学筛选页宽度390/390。
