## 发现与修复

- 手机底部有5个入口，容器却只有4列，导致「更多」落到第二行并被截断；改成单行5列、58px高。频道路径从「更多」匹配中移除，避免两个入口同时高亮。新增SSR回归检查实际渲染导航。
- 手机时间栏占用48px，卡片再加内边距后正文过窄；时间移入卡片信息行，卡片占满正文列。日期条同卡片边缘对齐；桌面日期与折叠控件不再挤出时间轴左边。长标题可显示3行并允许超长词换行。
- 四频道目录原本是3列，社会学独占第二行；宽屏4列、中屏2列、窄手机1列。卡片说明伸展、摘要分隔线对齐；单列时图标和标题共用一行，减少重复空白。
- 频道表单采用统一网格：桌面4字段加按钮，手机2×2字段和独立整行按钮。各行左右边缘、字段宽度和控件高度一致；搜索输入能正确收缩。空状态采用同一表面与边距，并提供最新内容或清除筛选入口。
- 日报保留着旧版负边距与280px满高侧栏，会打破当前页框；改成220px独立归档卡片，窄桌面与手机使用刊期导航。报头SVG改为按可用宽度缩放：修复手机「日报」被日期框遮住、合订本401px横向溢出的现象。日期数字使用直接文本，避免纹理绘制期间变淡或消失。
- 阅读布局统一页框并保持760px正文上限，适配220px右栏及宽屏三栏。长作者名单在手机放入「来源与时间」，全文信息仍可展开查看。更多页面的3组卡片在桌面并排。
- 内容筛选与领域导航在刷新、切换和窗口缩窄后保持当前选项可见；补验1440缩到320时，社会学与教程选项右边缘均在304px以内。
- OpenZoo在320px时把「世界」拆出孤字；小于等于380px使用34px标题，最终两行，高约80px，无横向溢出。
